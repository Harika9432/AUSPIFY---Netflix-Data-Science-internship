# AUSPIFY – Netflix Data Science Internship

A six-task Data Science project completed as part of the AUSPIFY internship. This project explores Netflix content data through data cleaning, exploratory analysis, recommendation systems, trend prediction, machine learning, and business insights.

## Project Overview

| Task | Project                         |
| ---- | ------------------------------- |
| 1    | Data Cleaning and Preprocessing |
| 2    | Exploratory Data Analysis (EDA) |
| 3    | Recommendation System           |
| 4    | Trend Prediction Analysis       |
| 5    | Machine Learning Classification |
| 6    | Business Insights Dashboard     |

## Tools and Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Plotly
* Kaggle Notebooks

## Project Tasks

### Task 1 – Data Cleaning and Preprocessing

Cleaned and preprocessed the Netflix dataset by handling missing values, duplicates, and data formatting.

### Task 2 – Exploratory Data Analysis

Explored Netflix content distribution, countries, genres, and release trends using visualizations.

### Task 3 – Recommendation System

Built a content-based recommendation system using TF-IDF and cosine similarity.

### Task 4 – Trend Prediction Analysis

Analyzed yearly content trends and used Linear Regression to forecast future trends.

### Task 5 – Machine Learning Classification

Implemented Logistic Regression and Random Forest classification models and evaluated their performance.

### Task 6 – Business Insights Dashboard

Created interactive visualizations and summarized business insights from the Netflix dataset.
